# Viddoc — Prototyp

Viddoc verwandelt eine Bildschirmaufnahme eines Arbeitsprozesses automatisch in eine
Schritt-für-Schritt-Dokumentation mit Screenshots.

Dieses Repo enthält den **Prototyp**: statische HTML-Seiten, kein Backend. Es wird kein
Video verarbeitet, die Seiten zeigen mit Beispieldaten, wie der Ablauf aussehen soll.

## Online ansehen
